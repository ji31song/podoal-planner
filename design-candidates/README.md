## 폰트 후보 1차 (표준 계열) — `font-preview.html`

1. 현재 (시스템 기본 Roboto/Noto Sans) — 실제로는 Pretendard가 CSS에 선언만 되어 있고 파일이 없어서 시스템 폰트로 표시되는 중
2. Pretendard — 요즘 앱 표준, 깔끔
3. SUIT — 기하학적, 단정
4. 나눔스퀘어라운드 — 부드러운 라운드
5. Gmarket Sans — 브랜드 개성

## 폰트 후보 2차 (얇고 아이 취향) — `font-preview2.html`

"덜 뚱뚱하고 어린아이들이 좋아할 만한" 방향. 미리보기 굵기도 800 → 600으로 낮춘 상태.

1. 고운돋움 (Gowun Dodum) — 동화책 느낌, 본문 가독성 좋음
2. 개구 (Gaegu) — 크레용 낙서 느낌
3. 하이멜로디 (Hi Melody) — 몽글몽글 손글씨
4. 동글 (Dongle) — 말랑한 라운드 (글자가 작게 나와 크기 보정 필요)
5. 푸어스토리 (Poor Story) — 동화 구연 손글씨
6. Pretendard 얇게 — 비교 기준

주의: 손글씨 계열(개구·하이멜로디·푸어스토리)은 시간표 숫자·긴 텍스트 가독성이 떨어질 수 있음.
조합안: 제목·버튼만 귀여운 폰트 + 본문 고운돋움/Pretendard.

## 적용 시 할 일

- 선택한 폰트는 한글 서브셋 woff2로 앱에 내장 (오프라인 동작 필요, 용량 +1~2MB 수준)
- `index.html`의 테마 변수(`:root`의 `--cream` 등, 376행 부근)와 튜토리얼·잠금 화면 배경까지 일괄 교체
- 적용 후 AAB 재빌드(VERSION_CODE 증가) + 스토어 스크린샷 재촬영 예정
